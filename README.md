# BeProductive

BeProductive is a full-stack productivity web application built with:

-  Frontend: React (Vite)
-  Backend: FastAPI (Python)
-  Database: PostgreSQL (Neon)
-  Deployment: Render (Backend), Vercel (Frontend)

---

# Project Overview

BeProductive helps users manage tasks, stay organized, and improve productivity through a simple and fast UI with a scalable backend API.
